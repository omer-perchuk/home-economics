# Home Economics WhatsApp Bot

בוט WhatsApp לניהול הוצאות והכנסות משפחתיות עם אתר לצפייה בנתונים.

זוהי גרסה ראשונה של המערכת.
המערכת תומכת במספר משפחות, וכל משפחה רואה רק את הנתונים שלה.

המערכת כבר רצה על שרת גלובלי ולכן **אין צורך להוריד את הפרויקט או להריץ אותו מקומית**.

Dashboard:
https://main.d11fqx2zyfwk68.amplifyapp.com

---

# התחברות לבוט

הבוט מחובר ישירות ל-WhatsApp Business API (Meta Cloud API) — אין צורך ב-Sandbox או במשפט הצטרפות מיוחד.

פשוט שולחים הודעת WhatsApp למספר הבוט, ובהודעה הראשונה המערכת תשאל:

1 לפתוח משפחה חדשה
2 להצטרף למשפחה קיימת (לפי מספר טלפון של מנהל)

לאחר מכן המשתמש כבר מחובר ומוכן לשימוש.

# הוראת קבע (תשלום חודשי קבוע)

תשלומים שחוזרים כל חודש (שכירות, ביטוח, ארנונה, מנוי וכו') אפשר להגדיר פעם אחת כהוראת קבע — הבוט יוסיף אותם אוטומטית כל חודש בלי צורך להזין אותם מחדש.

## הגדרת הוראת קבע

שלח:

הוראת קבע

אם אין עדיין הוראות קבע, הבוט יתחיל תהליך הוספה:

1. שם התשלום (למשל: שכירות)
2. סכום חודשי
3. קטגוריה
4. יום בחודש לחיוב (1-28)

דוגמה לתהליך מלא:

הוראת קבע
שכירות
3500
דיור וחשבונות
1

אם יום החיוב שנבחר כבר עבר החודש, הרשומה נוספת גם לחודש הנוכחי מיד.

## צפייה ומחיקה של הוראות קבע

שלח שוב:

הוראת קבע

הבוט יציג את רשימת ההוראות הפעילות. משם אפשר:

- לשלוח מספר הוראה (או כמה מספרים) כדי לבטל אותה
- לשלוח 'הוסף' כדי להוסיף הוראת קבע נוספת

- כל מספר טלפון משויך למשפחה

# הערות טכניות (למפתחים)

- הבוט מתחבר ל-WhatsApp דרך Meta Cloud API (`/webhook/whatsapp`), לא דרך Twilio.
- משתני סביבה נדרשים: `META_ACCESS_TOKEN`, `META_PHONE_NUMBER_ID`, `META_VERIFY_TOKEN`, `DATABASE_URL`, `OPENAI_API_KEY`.
- אין Alembic — שינויי סכימה מבוצעים ידנית מול מסד הנתונים.
- ה-Dockerfile של השרת נמצא ב-`docker/backend/Dockerfile`.
