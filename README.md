# Home Economics WhatsApp Bot

בוט WhatsApp לניהול הוצאות והכנסות משפחתיות עם אתר לצפייה בנתונים.

זוהי גרסה ראשונה של המערכת.  
בגרסה זו כל המשתמשים עובדים על אתר משותף אחד, והוספת משתמשים מתבצעת ידנית על ידי מנהל המערכת דרך הקוד.

המערכת כבר רצה על שרת גלובלי ולכן **אין צורך להוריד את הפרויקט או להריץ אותו מקומית**.

Dashboard:  
https://home-economics-flax.vercel.app
